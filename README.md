# matrix_spencer_lean
Matrix Spencer Lean 
This repository contains a lean proof of the Matrix Spencer (n matrices of size mxm of operator norm at most 1, want to prove the existence of signing such that the signed discrepancy is at most O(\sqrt{n})) conjecture. The proof is very different based on a recent Akbas-Sra proof that appeared while I was verifying my proof (manually) and writing it up (which I still am). Based on a suggestion by a friend, inspired by the emerging trend of time-stamping proofs via Lean -see for instance https://blog.computationalcomplexity.org/2026/09/navier-stokes-and-lean.html - before one has had time to write up the proof clearly), I decided to use GPT to formalize the proof in Lean and this is the result. This repo is private for now but will eventually be made public
